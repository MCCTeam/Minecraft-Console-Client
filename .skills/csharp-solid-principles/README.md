# csharp-solid-principles

A skill for pragmatic application of SOLID principles in modern C#/.NET code.

## Contents

- `SKILL.md` — trigger description, principles, review/refactoring workflow, and response guidance.
- `references/examples.md` — realistic Bad vs Good C# examples for SRP, OCP, LSP, ISP, and DIP, plus .NET DI lifetime guidance.
- `references/review-playbook.md` — diagnostic questions, prioritization, contract-test guidance, and common false positives.
- `references/sources.md` — Microsoft documentation, .NET ecosystem expert commentary, and foundational sources with interpretation notes.
- `evals/evals.json` — five realistic evaluation prompts and verifiable expectations.

The skill deliberately avoids cargo-cult rules such as “every class needs an interface,” “every switch violates OCP,” or “small classes are automatically SRP-compliant.”

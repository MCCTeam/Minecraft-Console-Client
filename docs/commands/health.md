# /health

Display Health and Food saturation.

## Syntax

```text
/health
```

## Forms

| Form | Meaning |
| --- | --- |
| `/health` | show health, food and experience |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/health
```

## Behavior and requirements

This reads your player's health, food, saturation, and experience information from the current session. It does not heal the player. Wait until the client joins the game before using it.

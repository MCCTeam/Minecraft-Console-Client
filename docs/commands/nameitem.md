# /nameitem

Rename the item in an open anvil.

## Syntax

```text
/nameitem <name>
```

## Forms

| Form | Meaning |
| --- | --- |
| `/nameitem <name>` | rename the item in an open anvil |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/nameitem Sharp Stick
```

## Behavior and requirements

Open an anvil and place the item in its input. This command changes the rename text for that menu. The server controls the cost and output. Collecting the result remains an inventory action.

Declared game features: Inventory. Some forms also need a current game session or a compatible menu.

# /mcc-menu

Open the main TUI management menu.

## Syntax

```text
/mcc-menu
```

## Forms

| Form | Meaning |
| --- | --- |
| `/mcc-menu` | Open the management menu. |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/mcc-menu
```

## Behavior and requirements

This opens the TUI's main menu. `Ctrl+M` opens the same menu from the main surface. Classic mode reports that this visual action needs the TUI.

The menu groups documentation, scripts, plugins, marketplaces, server selection, game browsers, and client exit.

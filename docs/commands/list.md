# /list

Get the player list.

## Syntax

```text
/list
```

## Forms

| Form | Meaning |
| --- | --- |
| `/list` | list the players online |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/list
```

## Behavior and requirements

This prints players reported through the server's player-list data. It can include players outside your visible chunks. Use `/tab` for the richer server tab-list display.

# /effects

List your currently active effects.

## Syntax

```text
/effects
```

## Forms

| Form | Meaning |
| --- | --- |
| `/effects` | list your active status effects |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/effects
```

## Behavior and requirements

This reads your active player effects. Names depend on available game translations. The command does not apply or remove an effect.

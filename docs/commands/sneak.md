# /sneak

Toggles sneaking.

## Syntax

```text
/sneak
```

## Forms

| Form | Meaning |
| --- | --- |
| `/sneak` | toggle sneaking |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/sneak
```

## Behavior and requirements

The command toggles the player's sneaking state. Run it again to change back. Server and protocol behavior determine the resulting movement or interaction.

Declared game features: Terrain. Some forms also need a current game session or a compatible menu.

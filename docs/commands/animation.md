# /animation

Swing your arm.

## Syntax

```text
/animation <mainhand|offhand>
```

## Forms

| Form | Meaning |
| --- | --- |
| `/animation mainhand` | swing your main hand |
| `/animation offhand` | swing your off hand |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/animation mainhand
```

## Behavior and requirements

This requests an arm swing. It does not damage an entity or break a block. Use `/entity ... attack` or `/dig` for those actions. Offhand behavior depends on the protocol.

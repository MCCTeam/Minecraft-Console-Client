# /respawn

Use this to respawn if you are dead.

## Syntax

```text
/respawn
```

## Forms

| Form | Meaning |
| --- | --- |
| `/respawn` | respawn after dying |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/respawn
```

## Behavior and requirements

This asks the server to respawn a dead player. It needs a current session with confirmed death state. It does not heal a living player. The server chooses the respawn location.

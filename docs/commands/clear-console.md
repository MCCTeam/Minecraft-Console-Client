# /clear-console

Clear the classic screen or the TUI log pane.

## Syntax

```text
/clear-console
```

Aliases: `/cc`.

## Forms

| Form | Meaning |
| --- | --- |
| `/clear-console` | clear the console screen |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/clear-console
```

## Behavior and requirements

The alias is `/cc`. In classic mode, it clears the terminal display. In the TUI, it clears the visible log pane. It does not delete log files, diagnostics, or script data.

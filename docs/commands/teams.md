# /teams

List all scoreboard teams and their members.

## Syntax

```text
/teams
```

## Forms

| Form | Meaning |
| --- | --- |
| `/teams` | list scoreboard teams and their members |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/teams
```

## Behavior and requirements

This lists scoreboard teams and their members as reported to the client. It does not create or modify teams. Server-side team membership can differ from what the server exposes to this client.

# /log

Log some text to the console.

## Syntax

```text
/log <text>
```

## Forms

| Form | Meaning |
| --- | --- |
| `/log <text>` | print text to the console, without sending it |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/log checkpoint reached
```

## Behavior and requirements

This prints text locally. It does not send chat or a server command. Use it to identify checkpoints in a transcript. Client variables can expand in local command text.

# /enchant

Click an option in an open enchanting table.

## Syntax

```text
/enchant <top|middle|bottom>
```

## Forms

| Form | Meaning |
| --- | --- |
| `/enchant top` | click the first enchantment option |
| `/enchant middle` | click the second |
| `/enchant bottom` | click the third |

## Examples

Type these lines inside MCC. Replace names, coordinates, IDs, and paths with values from your installation.

```text
/enchant top
```

## Behavior and requirements

Open a real enchanting-table menu first. Place the item and required materials in that menu. `top`, `middle`, and `bottom` select its three server-provided choices.

The server checks experience levels, materials, and menu state. The command does not choose arbitrary enchantments.

Declared game features: Inventory. Some forms also need a current game session or a compatible menu.

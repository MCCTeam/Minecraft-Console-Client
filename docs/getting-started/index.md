# Getting started

These pages take you from an installed client to a working connection.

1. [Install MCC](installation.md).
2. [Connect and send your first message](first-session.md).
3. [Learn the startup options](arguments.md).
4. [Save your accounts and settings](../client/configuration.md).

You need a Minecraft Java Edition server address. A normal online server also requires a Microsoft account that can play Minecraft Java Edition. An offline account works only when the server permits it.

You can inspect help and test Beacon files without a server. A live session is required for game actions.

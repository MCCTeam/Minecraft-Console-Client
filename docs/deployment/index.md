# Run MCC outside your desktop

MCC can run from a release folder, from source, or in a container. Each process owns one client connection and its runtime files.

Choose a guide:

- [Docker Compose](docker.md): build an image and keep accounts, plugins and scripts in a persistent volume.
- [Release packages](releases.md): package MCC executables and publish early-access builds.
- [Installation](../getting-started/installation.md): install or build MCC on your computer.
- [Diagnostics](../troubleshooting/index.md): investigate a failed connection or a closed process.

For an unattended client, prepare its account and server profiles first. Interactive authentication can require a browser or a code.
